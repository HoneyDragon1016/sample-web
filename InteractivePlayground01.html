Experiment 01

3D 傾斜流光卡

滑鼠座標即時換算 rotateX / rotateY， 邊緣帶有隨光標移動的鏡面流光（Specular Glare）。觸控裝置自動停用傾斜，保留捲動順暢度。

Perspective Tilt

以 gsap.quickTo 建立低延遲補間，指標移動即時映射 3D 角度，離開時以彈性曲線回正。

transform only · 0 repaint

Experiment 03

Web Audio 微聲效

右上角的聲效開關啟用後，滑過或點擊卡片會由瀏覽器原生 OscillatorNode 即時合成極短高頻「微晶片點擊聲」——不載入任何音訊檔案，零網路成本。

  • Hover 微聲：3.2kHz 正弦波、30ms 極短包絡，音量低至 0.03。

  • 點擊回饋：1.8kHz 雙音階短促下潛，模擬機械微動開關。

  • 無障礙：預設關閉、需使用者手勢啟用；尊重系統減少動態偏好。

Tech Stack

Web Audio API · Canvas 2D · Pointer Events · requestAnimationFrame · gsap.quickSetter
